# Low Level Programming in C

Welcome to the **Low Level Programming** repository, part of the curriculum at [Holberton School](https://www.holbertonschool.com/).  
This project explores the fundamentals of programming in **C**, focusing on understanding how code works under the hood, including memory management, data structures, pointers, compilation, and more.

## 🧠 Project Objectives

- Understand the basics of the C language
- Learn how programs are compiled and executed
- Master the use of pointers and memory management
- Implement custom functions and recreate parts of the C standard library
- Explore data structures like arrays, linked lists, and hash tables
